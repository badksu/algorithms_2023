Док прибывает на финальную гонку, осознав свою ошибку. Он застал некоторые фрагменты гонки, а именно $N$ фрагментов
с $l_{i}$-й по $r_{i}$-ю секунды.

Для полного анализа ситуации и выработки дальнейшей стратегии для победы над Чико и Кингом необходимо провести
комплексный анализ увиденного. А для этого сначала надо объединить все отрезки, что он видел. Помогите Доку!

### Формат ввода

На первой строке идет число
$N$ $(1 \leq N \leq 10^{5})$ — число увиденных фрагментов гонки. Далее идут $N$ строк по два
числа $l_{i}$, $r_{i}$ $(1 \leq l_{i} \leq r_{i}\leq 10^{9})$ — начало и конец $i$-го фрагмента.
