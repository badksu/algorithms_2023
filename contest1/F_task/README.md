# F. k-я порядковая статистика
***

|                     | Все языки                         | (make) Java 21 (Temurin JDK) |
|---------------------|-----------------------------------|------------------------------| 
| Ограничение времени | 	3 секунды                        | 	5 секунд                    |
| Ограничение памяти  | 64 Мб                             | 64 Мб                        |
| Ввод                | стандартный ввод или input.txt    |
| Вывод               | 	стандартный вывод или output.txt |

В этой задаче вам необходимо найти $ k $-ую порядковую статистику ( $ k $-ое по неубыванию) числовой последовательности $ A $, элементы которой задаются следующим образом:

$ A i ​ =(A_{i−1} ⋅123+A_{i−2}⋅45)\mod\ (10^{7} +4321) $

### Формат ввода 
 Вам даны $ n,\ k\, A_{0}\, A_{1}\ (1 \leq k \leq n \leq 10^{7},\ 0 \leq A_{i} < 10^{7} + 4321) $

### Формат ввывода 
Выведите $ k $-ую порядковую статистику.

### Примеры
| Ввод         | Вывод  |
|--------------|--------|
| 2 2 100 1000 | 1000   |
| 10 5 1 2     | 321287 |
