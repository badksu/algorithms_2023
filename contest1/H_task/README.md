# H. Быстрая сортировка

***

|                     | Все языки                         | (make) Java 21 (Temurin JDK) |
|---------------------|-----------------------------------|------------------------------| 
| Ограничение времени | 	1 секунды                        | 	2 секунд                    |
| Ограничение памяти  | 64 Мб                             | 256 Мб                       |
| Ввод                | стандартный ввод или input.txt    |
| Вывод               | 	стандартный вывод или output.txt |

Нужно с помощью быстрой сортировки отсортировать массив.

### Формат ввода

Вам дано $n\ (1 \leq n \leq 10^{5})$. Далее идет $n$ чисел, числа не превосходят по модулю $10^9$.

### Формат вывода

Вывести отсортированный по неубыванию массив.

### Примеры

| Ввод        | Вывод     |
|-------------|-----------|
| 5 5 2 3 1 4 | 1 2 3 4 5 |
