# B. Вкус салата

***

|                     | Все языки                         | (Make) Clang 17.0.1 C++20 |
|---------------------|-----------------------------------|---------------------------| 
| Ограничение времени | 	2 секунды                        | 	1 секундa                |
| Ограничение памяти  | 32 Мб                             | 32 Мб                     |
| Ввод                | стандартный ввод или input.txt    |
| Вывод               | 	стандартный вывод или output.txt |

В Бикини Боттом объявлен новый конкурс на лучший салат из водорослей! Все водоросли, собранные со дна океана, Сэнди
аккуратно расположила в длинный ряд прямо на прилавке перед рестораном "Красти Крабс". Она пронумеровала растения от $1$
до $N$, чтобы было проще анализировать отзывы покупателей.

У каждой водоросли есть показатель питательности $a_{i}$. Сэнди мечтает узнать, какие комбинации соседних водорослей
окажутся самыми питательными для нового фирменного салата.
Для этого она учла советы подводных гурманов: вкус салата определяется средним геометрическим питательности выбранных
подряд идущих водорослей.

Напомним, что среднее геометрическое вычисляется по формуле:
$$ \sqrt[r - l + 1]{a_{l} * a_{l + 1} ... * a_{r}}$$

### Формат ввода

В первой строке дано число $N$, $(1 \leq N \leq 3 * 10^{5})$— число сортов водорослей. На второй строке идут $N$
вещественных чисел $(0.01 \leq a_{i} \leq 10^{3})$ с двумя знаками после десятичной точки — питательность $i$-го сорта.

На третьей строке идет единственное число $Q$ $(1 \leq Q \leq 10^{5})$ — число запросов подсчета вкуса салата на
подотрезке.

Далее идет $Q$ строк запросов в формате $«i j»$ $(0 \leq i \leq j \leq N - 1): i, j$ — индексы массива, задающие отрезок
для запроса.

### Формат вывода

Для каждого запроса на новой строке выведите полученную питательность салата с точностью до не менее шестого знака после
запятой.
